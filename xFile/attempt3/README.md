# xFile
A personal project to store arbitrary persistent data inside the executable itself rather than an external file. I aim to support Win7+ and POSIX systems. Written in C++20 using as little non-portable code as possible. This project is only a curiosity and exists as an educational exercise. This utility, in fact, has very little utility; it's an over-complicated solution to an otherwise non-existent problem.


As a good friend said:
